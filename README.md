# Tablero del Asistente de Tesis

Tablero Scrum y cronograma de mi proyecto de graduación **Asistente Web para la Planificación de Tesis** (Ingeniería en Sistemas, Universidad Mariano Gálvez de Guatemala).

Página publicada: https://enriquepinelo.github.io/asistente-tesis-tablero/

* `index.html`: la página del tablero, con dos vistas (Cronograma y Tablero Kanban).
* `datos.json`: los sprints y los ítems del backlog. Cada avance se registra como un commit que cambia este archivo.

Repositorios del sistema:
* Backend: https://github.com/Enriquepinelo/asistente-tesis-backend
* Frontend: https://github.com/Enriquepinelo/asistente-tesis-frontend

Los sprints S1 a S6 los reconstruí al final a partir de mi trabajo y mis entregas. Desde el sprint S7 (24 de octubre de 2026) registro el avance en tiempo real, con un commit por ítem.
